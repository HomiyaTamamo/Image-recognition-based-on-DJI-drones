## 🛠️ 系统全流程闭环架构 (System Architecture)

本系统实现了从**无人机动态视场拉流**到**地物要素高精度地理坐标解算**的完整闭环，核心链路如下：

1. **前端数据拉流与同步**：通过 MQTT 异步轻量化网关，实时拉流大疆 M4E 视频帧，并在后台无感流式截取瞬时高精度 OSD 空间状态向量。
2. **边缘智能要素识别**：基于在航拍基准数据集（VisDrone2019）上经过 200 Epoch 深度迭代优化的 YOLOv8m 改进网络，对视场小目标进行毫秒级捕获，锁定目标像素中心坐标。
3. **多坐标系空间交会投影**：
   * **像素坐标系 $\rightarrow$ 相机坐标系**：依托内参矩阵 $K$ 执行小孔成像模型逆映射。
   * **相机坐标系 $\rightarrow$ 云台坐标系 $\rightarrow$ 地理大地坐标系**：应用高频三轴姿态角构建旋转矩阵，将空间射线投影至地表平面。
4. **地球曲率修正与最终收敛**：结合机身绝对海拔高度 $H$、地球平均半径 $R_e$，利用大圆几何模型实时结算出目标的真实经纬度，并将数据动态渲染回直播流。

### 📐 标定实验设计原理（自回归式地面基准差分校验法）
为了彻底排除第三方测绘仪器引入的外部误差，本工具采用测绘学闭环标定思路：
1. **获取真值 $P_1$**：起飞前，将无人机直接放置在待测地物要素（如操场、椅子）正上方，记录大疆原生 RTK  सेंटीमीटर（厘米）级的静态地理坐标作为刚性真值 $(Lat_1, Lon_1)$。
2. **获取预测值 $P_2$**：操控无人机升空至作业高度（如 $100\text{ m}$ 级高空），在倾斜视角下运行本项目标捕获算法，系统会自动通过图像反解出目标的地理预测坐标 $(Lat_2, Lon_2)$。

## 📂 项目文件清单与核心用途 (Repository Artifacts)

本仓库包含了从前期方案探索、数据监听调试、模型训练对比，到最终系统集成的全套 Python 源码。各脚本核心用途简明总结如下：

### 🎯 1. 核心系统集成方案 (System Implementations)
* **`ceshi.py` — 无人机实时定位识别系统（流式完整版）**
  系统的完全体形态。通过 MQTT 实时高频捕获大疆无人机 OSD 空间状态向量，同步拉取 HDMI 视频流，在边缘端部署 YOLOv8s 实时捕获目标，并将像素坐标动态反算为实时 GPS 经纬度渲染输出。
* **`ceshi2.py` — 无人机实时定位识别系统（异步回退版）**
  系统架构的轻量化演进。在核心功能基础上引入了**帧回退显示机制**。当 YOLO 前向传播算力受限出现断帧时，自动回退渲染原始视频帧，保障直播流整体的毫秒级低延迟响应。
* **`ceshi3.py` — 无人机实时定位识别系统（三维交会高精度版）**
  系统的最终高精度形态。全面废弃了初级的平面投影，深度引入**针孔相机内参模型与 3D 空间旋转矩阵 $R$**。将云台（Pitch/Roll）三轴微晃角度彻底解耦入空间射线，实现厘米级 RTK 底座下的高精度地面求交解算。

### 📊 2. 模型训练与评测工具 (Training & Evaluation)
* **`模型训练.py` — VisDrone 数据集边缘端训练脚本**
  自研的数据转换与训练管道。自动将 VisDrone 原始的天大标注格式转化为规范化 YOLO 格式。全线激活 Mosaic、Mixup 等强数据增强策略，驱动 YOLOv8m 权重在边缘视场下执行 200 Epoch 的深度迭代优化。
* **`compare_models.py` — 异构模型性能基准对比工具**
  论文第四章核心图表的生成源。在完全锁定随机种子、确保实验 100% 可复现的前提下，自动化比对深度优化版 YOLOv8m、Vanilla YOLOv8m 与 Vanilla YOLO11m 在测试集上的 mAP@0.5 与单张推理延迟，一键生成双 Y 轴学术可视化柱状图/折线图。

### 📐 3. 定位精度校验（论文第三、四章数学支撑）
* **`误差计算.py` — WGS84 高精度几何定位误差校验系统**
  论文闭环验证的刚性基准工具。基于** Vincenty 椭球解析算法**（相较于基础大圆距离具备更高的测绘级地球曲率拟合精度），提供 Tkinter GUI 图形交互界面，通过“地面静态 RTK 打点 $(Lat_1, Lon_1)$ vs 空中动态交会反算 $(Lat_2, Lon_2)$”执行空间差分校验，科学定量系统残差。

### 🔌 4. MQTT 异步总线与硬件通信调试 (Data Protocol & Debugging)
* **`经纬度.py` — DJI OSD 数据高频监听器**
  流式状态解包接口。通过 MQTT 异步总线订阅遥控器侧行协议，每秒定时解析并结构化输出：搜星数、RTK 定位质量、机身三轴姿态、绝对海拔高度及电量等核心遥测向量。
* **`经纬度1.py` — DJI 协议修复与全量数据监听器**
  针对新硬件（M4E 等）上云 API 瘫痪的底层修复脚本。内嵌 `update_topo` 握手协议自动应答逻辑，维持链路保活，并实现了云台（Gimbal）独立姿态角的二次提取。
* **`云台测试.py` — DJI MQTT 通信协议全量调试器**
  底层协议逆向利器。连接大疆内置 Broker 后强制订阅全部 `sys` 与 `thing` 拓扑主题，全量打印 JSON 报文，用于前期地毯式搜索和捕获隐藏在私有协议中的姿态、高度等关键数据元。
* **`直播测试.py` — HDMI 视频流硬件采集调试器**
  高固定资产开销（HDMI线及采集卡）的硬件链路调测脚本。打通硬解码通道，实时校验画面输入分辨率、瞬时稳定 FPS，并支持一键（S键）截取单帧航拍背景图。

### 📜 5. 前期探索性历史脚本（技术演进路线佐证）
* **`main.py` — 离线视频行人检测器**
  项目初期的已知问题转化方案。读取本地 `ceshi1.mp4` 离线文件，调用轻量化 YOLOv8n 在 COCO 目标域（类别0）执行纯像素级的行人边界框检测与计数统计。
* **`main2.py` — 离线视频行人几何定位器**
  早期的离线定位尝试。在 `main.py` 基础上尝试静态引入经纬度换算，为离线视频中的行人目标打上估算的地理标记。
* **`字幕提取.py` — 离线 OSD 字幕元数据提取工具**
  研制初期**“离线外置字幕轨方案”**的物理残存脚本。调用 `ffprobe`/`ffmpeg` 自动抽离大疆本地录像文件中的 OSD 经纬度字幕流并导出为 SRT 文件。后因“实时无线图传（Live Streaming）模式下不随流封装字幕”导致该技术路线在实时化重构中胎死腹中。
