## 🛠️ 系统全流程闭环架构 (System Architecture)

本系统实现了从**无人机动态视场拉流**到**地物要素高精度地理坐标解算**的完整闭环，核心链路如下：

1. **前端数据拉流与同步**：通过 MQTT 异步轻量化网关，实时拉流大疆 M4E 视频帧，并在后台无感流式截取瞬时高精度 OSD 空间状态向量。
2. **边缘智能要素识别**：基于在航拍基准数据集（VisDrone2019）上经过 200 Epoch 深度迭代优化的 YOLOv8m 改进网络，对视场小目标进行毫秒级捕获，锁定目标像素中心坐标 $P_{uv} = [u, v, 1]^T$。
3. **多坐标系空间交会投影**：
   * **像素坐标系 $\rightarrow$ 相机坐标系**：依托内参矩阵 $K$ 执行小孔成像模型逆映射。
   * **相机坐标系 $\rightarrow$ 云台坐标系 $\rightarrow$ 地理大地坐标系**：应用高频三轴姿态角构建旋转矩阵 $R = R_z(\psi)R_y(\theta)R_x(\phi)$，将空间射线投影至地表平面。
4. **地球曲率修正与最终收敛**：结合机身绝对海拔高度 $H$、地球平均半径 $R_e$，利用大圆几何模型实时结算出目标的真实经纬度 $[Lon_t, Lat_t]$，并将数据动态渲染回直播流。

## 📊 定位精度定量验证 (Accuracy Verification Guide)

为了让用户客观、科学地评估系统在实际工程落地中的表现，项目根目录下提供了 `误差计算.py` 验证程序。

### 📐 标定实验设计原理（自回归式地面基准差分校验法）
为了彻底排除第三方测绘仪器引入的外部误差，本工具采用测绘学闭环标定思路：
1. **获取真值 $P_1$**：起飞前，将无人机直接放置在待测地物要素（如操场、椅子）正上方，记录大疆原生 RTK  सेंटीमीटर（厘米）级的静态地理坐标作为刚性真值 $(Lat_1, Lon_1)$。
2. **获取预测值 $P_2$**：操控无人机升空至作业高度（如 $100\text{ m}$ 级高空），在倾斜视角下运行本项目标捕获算法，系统会自动通过图像反解出目标的地理预测坐标 $(Lat_2, Lon_2)$。
3. **绝对几何残差结算**：运行 `误差计算.py`，程序内部将严格依据 **Haversine 核心公式** 求解球面中心角与弦长比例，在考虑地球曲率的极限条件下，吐出两点间最终的绝对物理定位误差距离 $D$：

$$\Delta\varphi = (Lat_2 - Lat_1) \times \frac{\pi}{180}$$
$$a = \sin^2\left(\frac{\Delta\varphi}{2}\right) + \cos(\varphi_1)\cos(\varphi_2)\sin^2\left(\frac{\Delta\lambda}{2}\right)$$
$$D = R \times 2\operatorname{atan2}(\sqrt{a}, \sqrt{1 - a})$$

### 📈 实飞测试收敛表现
在实际百米高空、全动态下视拉流、长焦镜头边缘存在轻微径向畸变的极限测试场景下，本系统内置的交会算法表现出了极佳的抗噪鲁棒性：
* **系统最终绝对物理定位几何误差稳定收敛在 6.961 米**。
* 该精度在完全不依赖地面控制点（GCP）后验修正的单目弱先验视场下，已达到行业高水平初筛准度，完美适配应急交通管理、移动要素追踪等地理信息工程的实用限差。
